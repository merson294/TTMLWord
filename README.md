# TTMLWord
TTMLWord is an intuitive, desktop-based word-level TTML lyric editor designed specifically for creating and fine-tuning synchronized lyrics for Apple Music and Spicy Lyrics.   I built this project because I couldn't find an existing TTML editor that was truly comfortable and convenient for precise word-by-word timing. TTMLWord fixes that by providing a smooth, effortless workflow for syllable-by-syllable editing using interactive timelines, tap-to-sync controls, custom CSS themes, and a live karaoke preview window.
